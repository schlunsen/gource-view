Two visualizers, one playlist

A new story every minute.

The screen saver alternates between the two, starting with a random one, and crossfades to a new repository or GitHub profile every minute. Each display gets its own shuffled playlist.

GourceView

Repository history, animated

Replays a public GitHub repository's commits as a growing file tree, with the people behind them. When the history reaches today it rewinds and plays again.

Git City

A GitHub profile as a city

Builds a 3D city from a user's public repositories and plays back their last 90 days of activity, with cinematic fly-through tours, weather, and day and night.

Features

Made for a screen saver.

  • Full-screen, every display

    Runs edge to edge on each screen, with the web controls hidden so only the visualization and its info panels show.

  • Smooth crossfades

    The next scene loads behind the current one and fades in once it's ready, so you never see a loading page.

  • Your projects

    Pick the GitHub users and repositories to show, or keep the featured ones.

  • Mood controls

    Set Git City's time of day, weather and old-TV look, and GourceView's playback speed from 0.5× to 4×.

  • Quiet

    Never plays sound. Any key or mouse movement wakes your Mac as usual.

  • Signed and notarized

    Signed with a Developer ID and notarized by Apple, so macOS opens it without warnings.

Install

Up and running in a minute.

  1. Download Git-Visualizer-Screen-Saver.zip and open it to unzip Git Visualizer.saver.
  2. Double-click Git Visualizer.saver. System Settings asks whether to install it for you or for all users.
  3. Choose it in System Settings › Screen Saver, then click Options… to pick users, repositories and how often it switches.
FAQ

Questions

Is it free?

Yes. It's free to download and use.

Does it need an internet connection?

Yes. Both visualizers load live from GitHub Pages, and repository histories and profiles come from GitHub.

Which Macs does it run on?

Macs with macOS 14 Sonoma or later, on Apple silicon or Intel.

Why isn't it on the Mac App Store?

A screen saver has to be installed into the system's screen saver folder, and the Mac App Store only allows apps that are fully self-contained. It's distributed here instead, signed with a Developer ID and notarized by Apple.

Can I show my own repositories?

Yes. Open System Settings › Screen Saver, choose Git Visualizer, click Options… and type GitHub usernames and owner/repo names. Public repositories only.

How do I uninstall it?

In System Settings › Screen Saver, Control-click Git Visualizer and choose Delete. Or remove ~/Library/Screen Savers/Git Visualizer.saver.
